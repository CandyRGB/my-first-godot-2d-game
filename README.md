# My First Godot 2D Game

这是我第一次学习 **Godot 引擎** 制作 2D 游戏的过程记录。

## 关于本项目

本项目用于记录我从零开始学习 Godot、逐步搭建一个 2D 游戏的全过程。代码和资源会随着学习进度不断更新，保留每一步的实践痕迹。

## 学习参考

本项目跟随 Godot 官方中文教程《制作你的第一个 2D 游戏》进行学习：

- 官方教程：<https://docs.godotengine.org/zh-cn/4.x/getting_started/first_2d_game/index.html>
- Godot 官方文档（中文）：<https://docs.godotengine.org/zh-cn/4.x/>

## 环境

- **引擎版本**：Godot 4.6
- **渲染方式**：GL Compatibility（兼容模式）
- **游戏窗口**：480 x 720（竖屏）

## 目录结构

```
first_2d/
├── art/            # 美术与音频资源（角色、敌人、音效、背景音乐等）
├── fonts/          # 字体文件（Xolonium）
├── scenes/         # 游戏场景（main / player / mob / hud）
├── scripts/        # GDScript 脚本（main / player / mob / hud）
├── icon.svg        # 项目图标
└── project.godot   # Godot 项目配置文件
```
